## 1. ソフトウェア概要

Grid Path Generator v2 は、

**一定間隔（STEP=10）の格子点集合に対し、
物理的に許容された移動長のみを用いて、
全点を一度ずつ通過する連続走査パスを生成するツール**

である。

### 主な用途

- ガルバノスキャナ走査パス生成
- XY ステージ一筆書き走査
- OCT / レーザ計測における測定順序設計

---

## 2. 問題設定（数理モデル）【最重要】

### 2.1 グラフとしての定式化

格子点集合を以下のグラフとして定義する。

```
G = (V, E)
```

- V：格子点集合（STEP = 10 の等間隔点）
- E：物理的に許容された移動のみを辺として持つ集合

#### 許可される移動（辺）

点 (x_i, y_i) から (x_j, y_j) への移動が許可される条件：

```
(x_j - x_i)^2 + (y_j - y_i)^2 ∈ {100, 200}
```

- 100 ：直交移動（距離 10）
- 200 ：斜め移動（距離 10√2）

これは **実機のステージ／ガルバノの移動制約を直接反映**している。

---

### 2.2 求める解（Hamiltonian Path）

求めるパス P は、

```
P = (v1, v2, …, v|V|)
```

で表され、以下を満たす必要がある。

- 全ての頂点を **ちょうど 1 回ずつ**訪問する
- 隣接点間のみで構成される

この問題は一般に **Hamiltonian Path 問題（NP 困難）**であり、
サイズが少し増えるだけで全探索は現実的に不可能となる。

---

## 3. 入力制約の意味（なぜ制限が必要か）

### 3.1 Width / Height（20〜200）

- 実際の走査サイズを想定した上限
- 点数増加による探索空間の指数爆発を防止

---

### 3.2 |X − Y| < 80 制約（非常に重要）

この制約は UI 上の都合ではなく、**探索理論上の安全装置**である。

- 細長い長方形では袋小路が必然的に発生
- Hamiltonian Path が存在しないケースも多い

> 解が存在しない、または極端に探索困難なケースを
> 入力段階で排除することが目的

---

## 4. アルゴリズム全体像（設計思想）【核心】

本ソフトは以下の **2 段階構成**で動作する。

```
(1) 決定的スパイラルで安全な領域を先に確定
(2) 残り領域を制約付き DFS で探索
```

この構成により、

- 探索空間を大幅に削減
- 初期段階での失敗を回避

している。

---

## 5. 正方形グリッドの場合（Spiral Only）

- 中心からの直交スパイラルで全点を被覆
- 探索不要・バックトラックなし
- 計算量 O(N)

最も安全かつ高速なケースである。

---

## 6. 非正方形グリッドの場合（Spiral + Search）【最重要】

### 6.1 Spiral Seed

- 短辺に収まる最大正方形領域を抽出
- その内部をスパイラルで完全被覆
- 探索が最も失敗しやすい中央部を先に固定

---

### 6.2 スパイラル向きの自動最適化

8 通りのスパイラルを評価し、
終端が長軸方向に最も偏るものを選択。

```
score = |x_end|  または  |y_end|
```

出口方向を意図的に作ることで探索成功率を高める。

---

### 6.3 Hamiltonian 探索（制約付き DFS）

#### Warnsdorff ヒューリスティック

- 次の候補の未訪問隣接点数が最小の点を優先
- 自由度の低い点を先に処理し詰みを回避

#### 長軸バイアス

- 外側方向への進行を優先
- 内部閉じ込みを防止

#### タイムアウト制御

- 実用時間を超える探索を中断
- 失敗としてユーザーに通知

---

## 7. 制約チェック（最終検証）

生成されたパスに対し、全ステップで

```
(x_{i+1}-x_i)^2 + (y_{i+1}-y_i)^2 ∈ {100, 200}
```

を検証し、
物理的に不可能なパスは絶対に出力しない。
